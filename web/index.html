Connect TrustGraph to your agent
Use MCP to test permissions, propose a plan and prepare work for a human reviewer. Your agent never receives an approval or publication tool.
  1. Keep this local app running
    The web app owns the journal. MCP shares that same workspace and review history.
  2. Add the local MCP server
    Download the configuration below and merge its TrustGraph entry into your client's MCP settings. It contains this machine's executable and token-file paths, never the secret token. The Rust command connects over stdio to this running app.
    trustgraph mcp --url http://127.0.0.1:8080/mcp
  --token-file /path/to/data/mcp-token
  3. Try the reconciliation review
    Ask: “Use TrustGraph to inspect the workspace. Test all three documents for the Engineering repository. Explain the conflict, then propose a shareable plan and prepare it for my review. Stop before delivery.”
All source data, generation and delivery are synthetic. This MCP connection does not import 8090 documents or capture another agent's model context. To use it alongside Software Factory, connect both servers to the same coding agent.
