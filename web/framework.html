Verification, with boundaries

Test executions. Check bounded properties.

The simulator exercises concrete schedules and recovery behavior. Kani harnesses address bounded properties of the Rust permission model. Neither establishes that every integration captures all inputs, or that the whole framework is formally verified.

Verification scope & reproduction ↗
Capture

Data, not just request IDs.

Artifacts have identities. Each execution records named inputs and outputs. Reusing an output in another step connects the graph.

Compose

Types at the boundary.

Operation ports declare schema identities. The host validates payloads; the framework checks compatible connections and inherited access.

Enforce

A gate, not a guess.

Rust evaluates recorded evidence. The integration must capture all inputs and route effects through the gate. Unrecorded access is outside this guarantee.
