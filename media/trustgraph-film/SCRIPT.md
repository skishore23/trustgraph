## Voiceover

### 1
One bank. One coding agent. Two departments. Engineering owns a payment
reconciliation change. Fraud and Risk owns a confidential investigation. The
agent is legitimately allowed to help both.

### 2
The agent reads both sources and writes a patch. It may quote nothing private.
But the patch was created with restricted information in its context. Can it
be shared with Engineering?

### 3
TrustGraph follows the path: investigation, generation, proposed file,
Engineering repository. Rust checks the source permissions and blocks the
boundary. A human approval cannot grant missing source access.

### 4
The repair starts a fresh, isolated generation with Engineering requirements
and an approved specification. It does not reuse the restricted patch. If that
is insufficient, Risk must authorize another specification.

### 5
Approval names the exact patch, policy, and destination. Change any of them,
and the old approval no longer matches. The gate checks before the branch is
pushed and the draft pull request is opened.

### 6
Hydra D B stores the connected evidence: people, sources, transformations,
versions, permissions, approvals, and outcomes. The runtime reads it back.
Rust evaluates the relationships and coordinates the gated action.

### 7
Test policies in the simulator. Try different audiences, source access,
approval lifetimes, and execution requirements across multiple scenarios.
Inspect the counterexample before activating a change. The live agent still
needs current authorization.

### 8
For confidential decisions, regulated code changes, and software factories,
TrustGraph keeps the reason behind each release inspectable. The agent can
work across departments without everything it learns becoming available to
every department.

## Sound and edit

One consistent synthetic narrator, warm and confident, with space after the
questions. Three original instrumental cues: curiosity, boundary tension,
resolution. Quiet paper and pen accents identify state changes. Score ducks
under narration; final mix targets about −14 LUFS. Precise architecture labels
are composited as vector text, not generated inside an image. Every generated
asset has a Comfy job record. Real screens, if used, show genuine results.

## Fidelity

The bank documents are controlled test material. Source permissions and
audiences are explicitly configured; they are not imported bank IAM. HydraDB is a required evidence dependency;
Rust enforces rules. The simulator evaluates explicit hypothetical assumptions.
The publisher uses the authenticated GitHub adapter. Imported enterprise department ACLs and Composio are not presented as live.
